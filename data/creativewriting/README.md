# Creative writing data

This data is related to the creative writing task in the Tree of Thoughts paper.
In this task, an AI model is given 4 random sentences as input. The model's task
is to generate a coherent passage with 4 paragraphs that end with the 4 input
sentences respectively. This task is open-ended and exploratory, and it
challenges the AI model's creative thinking and high-level planning abilities.

The file `data_100_random_text.txt` contains 100 sets of 4 random sentences.
Each set of sentences is separated by a blank line. These sentences are used as
input for the AI model to perform the task.
